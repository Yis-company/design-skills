# Deprecated

Skills no longer used. They stay for reference: nothing in the plugin, the top-level README or `ask-design` routes to them.

- **[tdd](./tdd/SKILL.md)**: Test-driven development with a red-green-refactor loop. Retired when the set moved to designers, who stay read-only on production code.
- **[implement](./implement/SKILL.md)**: Build a spec or set of tickets with `/tdd`, then review. Retired for the same reason; engineers build from the tickets.
- **[implement-spec](./implement-spec/SKILL.md)**: Implement a whole spec on one integration branch with parallel implementer subagents. Retired for the same reason.
- **[setup-ts-deep-modules](./setup-ts-deep-modules/SKILL.md)**: Wire dependency-cruiser into a TypeScript repo so each package is a deep module. Retired with the deep-module vocabulary it depended on.
